
# Emotion Detection System

## Project Overview
- This project detects human emotions using Deep Learning.
- It can detect emotions from:
  - Live webcam feed
  - Uploaded image files
- The system uses TensorFlow/Keras for prediction and OpenCV for face detection.

---

## Features
- Real-time webcam emotion detection
- Emotion prediction from image files
- Face detection using OpenCV
- Deep learning model integration
- File browser support for image selection
- Displays emotion label with confidence score

---

## Emotions Detected
- Angry
- Disgust
- Fear
- Happy

## Installation

### Clone Repository

```bash
git clone https://github.com/12namitha-2003/emotion_dectection.git
```

### Move to Project Folder

```bash
cd emotion_dectection
```

### Install Required Libraries

```bash
py -3.10 -m pip install tensorflow opencv-python numpy
```

---

## How to Run

```bash
py -3.10 live.py
```

## Usage

### Option 1: Live Webcam Detection
- Opens webcam
- Detects face in real-time
- Predicts emotion instantly

### Option 2: Image Emotion Detection
- Opens file browser
- Select image
- Predicts emotion from uploaded image
